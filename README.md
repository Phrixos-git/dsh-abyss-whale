# 深海の大鯨テーマ（@local/dsh-abyss-whale）

DeepSeek Harness（DSH）の Web GUI 用テーマです。深い青と漆黒の深海をイメージし、
画面の下のほうを大鯨がゆっくり泳ぎます。

- 配色: 深淵のような黒に近い青（ベース `#04080f`）と、生物発光のようなシアンのアクセント
- 雰囲気: 上から差し込む光の筋、海雪（マリンスノー）、深海からのほのかな青い照り返し
- アートワーク: 画面下部を横切る大鯨。既定は、参考画像（発光する粒子で描かれた電子の鯨）に
  寄せて、写真版を ComfyUI（Qwen-Image 2.1）の img2img で「粒子＋星座の網」に描き直し、
  まわりにワイヤーフレームの箱と流れる光の筋を足した「ネオン版」です（追記10）。
  ほかに、写真版（追記5）・粒子版（追記8）・手描きの線画版（追記4）も入っていて、
  `WHALE_ART` ひとつで切り替えられます。外部ファイルは読まず、SVG（WebP の data URI）として
  `client.js` に埋め込んでいます。デフォルメせず、ザトウクジラの実寸の比率で描いています
- 設定: 設定 → 一般 に「深海の大鯨」のオン/オフ行を追加（ブラウザごとに保存）
- テーマ自体は `ctx.theme` にサードパーティテーマ `@local/dsh-abyss-whale` として登録

## 仕組み

1. クライアント側で `ctx.theme.register({ id: '@local/dsh-abyss-whale', colorScheme: 'dark', tokens })` を実行し、
   ビルトインのダークパレットの上に深海配色の `--dsw-*` トークンを重ねます。
2. インストール直後は自動でこのテーマを有効化します（`ctx.theme.setTheme('@local/dsh-abyss-whale')`）。
   DSH の永続設定はビルトインの light / dark / system のみを扱うため、サードパーティテーマの
   オン/オフは `localStorage`（`dsh.abyss-whale.enabled`）にブラウザ単位で保存します。
3. 設定 → 一般 の「深海の大鯨」行のスイッチでオン/オフできます。
   - オン: テーマを有効化（それまでの light / dark / system の選択は記憶）
   - オフ: 記憶していたビルトインの選択に戻す
   - 外観（Appearance）行で light / dark / system を選んだ場合も、この行は自動的にオフになります
     ので、リロードでテーマが勝手に戻ることはありません。
   - 設定の再読み込み（再接続など）やフォントサイズ変更のたびに DSH 側が保存済みの
     light / dark / system を再適用しますが、プラグインはその「設定の再適用」と
     「外観行でのユーザー操作」を区別し、テーマが勝手に外れないようにしています。
4. フレーム全体の装飾は `shell.overlay` スロットに登録します。3カラムより手前・
   スクロール領域の外側に置かれ、`pointer-events: none` なので操作の邪魔はしません。
5. `shell.overlay` は z-index を持つ独立したスタッキングコンテキストなので、
   `mix-blend-mode` で下のカラムの内容と混ぜることはできません。そのため鯨は
   「透明地に光で描く」方式（ごく薄い塗り＋発光する輪郭）で作り、文字の可読性を保っています。
6. テーマをオフにすると、配色だけでなくフレームの装飾（光の筋・海雪・大鯨）も消えます。
   装飾の表示は設定行のスイッチと同じ状態を共有しています。

## アートワーク（大鯨）

**既定はネオン版（`WHALE_ART = 'neon'`）** です。参考画像（暗い海を進む、無数の光る粒と
細い網で描かれたザトウクジラ）の雰囲気に寄せて、写真版のレンダーを ComfyUI の img2img で
「粒子＋星座の網」に描き直し、`tools/photo/neon_post.py` で黒い水を透明に抜き、青く調色して、
ワイヤーフレームの箱・流れる光の筋・水中のボケをまわりに足したものです（追記10）。
体の立体と解剖は写真版から引き継いでいるので、形はザトウクジラのままです。

`WHALE_ART` を変えると別の絵に切り替わります（配置・マスクはバリアント別に CSS で持っています）。

- `'neon'`（既定）: 発光する粒子と星座の網で描いた電子の鯨（追記10）
- `'photo'`: ComfyUI の生成画像をそのまま透明地にした写真版（追記5）
- `'lines'`: 同じレンダーを等高線なしの「光の粒」で描き直した粒子版（追記8）
- `'vector'`: 以下で説明する手描きの線画版

以下は**手描きの線画版（`'vector'`）**の説明です。デフォルメせず、ザトウクジラ
（Megaptera novaeangliae）の横向きの姿を実寸の比率で描いています。描き方（描画の手法）は
最初の版から変えていません。透明地に「ごく薄い塗り＋ぼかした発光＋光る輪郭」だけで
形を出します。

- 比率: 体長 880 単位（吻端→尾柄）に対して最大体高 155 単位（体長:体高 ≒ 5.7:1）。
  シロナガスクジラより胴が太く、尾柄も太い
- 頭部: 広く丸い吻（背に2列、下顎に1列の結節）、顎先に集まるしわ（5本）、口線は吻端から
  長く弧を描いて口角（眼のすぐ下）で上がる。噴気孔は眼より前方。口角までは体長の約 0.30
- 背びれ: 吻端から 0.68 の「こぶ」の上にある小さな鎌状の背びれ。その後ろに段（step）
- 腹側: 喉の畝（18本）が下顎の先で一点に集まり、臍のあたりまで扇状に走る。腹は淡く光り、
  白い斑をぼかして重ねる
- 胸びれ: 体長の 0.29 と極端に長い。前縁に結節の凹凸、先端側は白い面、長軸方向に条線、
  肩から後方下へ流れる
- 尾びれ: 幅は体長の 0.26。切れ込みは弦長の約 38%（深すぎると人魚の尾になるため実測に
  合わせた）。後縁は細かい鋸歯、付け根から後縁へ稜線が走る
- 陰影: 背と腹の輪郭に沿う陰影線を体の内側に引き、平らな切り抜きではなく丸い胴に見えるように
- 皮膚: 背のまだらと腹の白斑、頭部と尾びれの先端にフジツボ

輪郭は1本のパスで、塗り・ぼかした発光・輪郭の発光の3枚に同じ `d` を使い回しています
（その `d` は `clipPath` にも使い、内側のディテールを体の内側だけに描きます）。
畝・口線・噴気孔・結節・しわ・斑紋・陰影線・尾びれの稜線・フジツボ・腹の淡い光はこの
クリップの中に置くので、輪郭からはみ出しません。胸びれだけは別パスで、付け根を輪郭の
内側に置いています。胸びれの白い面と条線は、胸びれ自身の `clipPath` で内側にだけ描きます。

尾びれは「真横の胴」と「真上から見た尾びれ」を折衷した見せ方（縦に広げる）を最初の版から
踏襲しています。実測では尾びれの幅は体長の約 1/3 ですが、この構図では 0.26 に抑えて
画面の帯（`.aw-whale` のマスク）に収めています。

## 設定（オン / オフ）

| 場所 | 操作 |
|---|---|
| 設定 → 一般 → 「深海の大鯨」 | スイッチでオン / オフ（`localStorage` に保存） |
| 設定 → 一般 → 外観 | light / dark / system を選ぶとテーマから離脱（以後は自動でオンになりません） |
| プラグイン管理 | プラグイン自体を Off / Remove するとテーマも装飾も消えます |

`localStorage` のキー:

- `dsh.abyss-whale.enabled` … `'1'` / `'0'`
- `dsh.abyss-whale.restore` … オフに戻すときのビルトイン選択（`light` / `dark` / `system`）

## カスタマイズ

編集するのは `client.js` の次の3か所です。

| 定数 | 内容 |
|---|---|
| `ABYSS_TOKENS` | 配色。`--dsw-*` トークン名 → CSS 値 |
| `WHALE_ART` | アートワークの選択。`'neon'`（既定）・`'photo'`・`'lines'`・`'vector'` |
| `WHALE_LINES_SVG` | 粒子版の SVG（1200×560 の `<image>`。1440×672 の WebP（51 KB）を data URI で保持） |
| `WHALE_NEON_SVG` | ネオン版の SVG（1200×560 の `<image>`。1200×560 の WebP（198 KB）を data URI で保持） |
| `WHALE_PHOTO_SVG` | 写真版の SVG（1200×560 の `<image>`。1440×672 の WebP を data URI で保持） |
| `WHALE_SVG` | 線画版の大鯨の SVG（viewBox は 1200×560。輪郭1本＋内側のディテール＋胸びれ＋眼） |
| `STYLES` | 装飾・アニメーション・設定行の CSS |
| `MOTES` | 海雪の粒（位置 %、サイズ px、濃さ）。動きは `.aw-motes` の1本のドリフトで与える |

- 鯨の形（寸法・比率）を変えたい場合は `tools/whale-profile.mjs` のランドマーク
  （`TOP_HEAD` / `FIN_SEGS` / `BOTTOM` / `FLUKE_TIP_UP` / `FLUKE_TIP_LO` / `FLUKE_NOTCH` /
  胸びれの `root`・`tip`）を直して `node tools/whale-profile.mjs` を実行し、出力の
  `---SVG---` 以降を `WHALE_SVG` に差し替えます。自己交差・viewBox 内か・畝や斑紋や結節、
  陰影線・尾びれの稜線・胸びれの条線が体の内側か・胸びれの比率、といった検証結果も
  一緒に出力されます（このスクリプトはテーマの動作には不要です）。
- 胸びれを短くしたい／角度を変えたい場合は、`tools/whale-profile.mjs` の `root` と `tip` を
  直します。先端が下へ出過ぎる場合は `tip` の y を 383 前後までにすると、尾びれの下端と
  同じ高さに揃います。
- 配色だけ変えたい場合は `ABYSS_TOKENS` の値を変えるのが安全です。DSH のダークパレットが
  定義しているトークン名だけを使っており、名前が変わっても「見た目が変わる」だけで
  レイアウトは壊れません。
- 鯨を消したい場合は `Atmosphere` から `.aw-whale` の要素を外すか、`STYLES` の
  `.aw-whale` に `display: none` を足します。
- テーマで動いているのは海雪の層（`.aw-motes`）のゆっくりしたドリフトだけです（追記11）。
  止めたい場合は `STYLES` の `@media (prefers-reduced-motion: reduce)` が効きます
  （OS の設定で自動的に止まります）。

## 既知の制約

- DSH の外観（Appearance）行にはサードパーティテーマを並べる仕組みがないため、
  このテーマは「設定 → 一般」の独自行でオン/オフします。外観行の選択状態とは別物です。
- サードパーティテーマ ID はホストの永続設定スキーマに含まれないため、オン/オフは
  `localStorage`（ブラウザ単位）に保存されます。別のブラウザ・別プロファイルでは既定でオンです。
- 深い海の装飾は 3カラムより手前（`shell.overlay`）に描かれます。文字の可読性を保つため
  鯨は「光の輪郭＋ごく薄い塗り」で表現していますが、会話やメニューの上を光が横切ります。
  気になる場合は `STYLES` の `.aw-whale` の `opacity`（既定 0.35）を調整してください。
- アートワークは外部ファイルを読まず data URI で `client.js` に埋め込むため、
  ファイルサイズが大きくなります（現在 587 KB。4つの data URI を含む）。
  不要なバリアントを消せば軽くなります。
- コードブロックのシンタックスハイライト（Shiki）の色はダーク用の既定色のままです。
- アイコンやブランドマークの差し替え（`ThemeDefinition.icons`）は行っていません。

- 仕上げ: `neon_post.py` で黒地を輝度で透明に抜き（シルエットは穴埋め＋最大連結成分）、

### 2026-11-09 追記11: アイドル時の CPU を下げる（光条と鯨のアニメーションを停止）

- 依頼: 別セッションの計測で「DSH を開いたまま操作しないと CPU が 1 コア 100% 前後まで
  上がる」現象の主因がこのテーマの背景アニメーションだと分かり、その引継ぎに沿って修正しました
  （引継ぎの値: `.aw-sway` 約 72%、`.aw-drift` 約 22%、whale-chan-pet の `wc-bob` 約 8%、
  cube-ui 約 1%）。
- 変更（`client.js` のみ）:
  - `.aw-shafts`: `animation: aw-sway ...` を削除。`filter: blur(26px)` を持つ層の
    `transform` をアニメーションさせると、フレームごとに blur を焼き直すことになります。
    38 秒で ±1.5% しか動かず、止めても見た目は変わりません。
  - `.aw-whale`: `animation: aw-drift ...` を削除。`mask-image` 付きの最大 1900px の
    ラスタを毎フレーム合成し直していました。170 秒で数 % のドリフトは知覚できません。
  - どちらも `will-change: transform` も外しました（アニメーションが無いのに層を保持しない）。
    `@keyframes aw-sway` / `@keyframes aw-drift` は削除。
  - **海雪（`.aw-mote` 18 個）の個別アニメーションも廃止**しました。引継ぎでは約 2% と
    見積もられていましたが、実測では 18 個の個別アニメーションが約 40% を占めていました
    （1 フレームのコストはページ全体の再合成で決まるため、小さい要素でも数が効く）。
    代わりに `.aw-motes`（海雪の層）に 96 秒の transform アニメーションを 1 本だけ置き、
    粒の層ごとゆっくり漂わせています（約 3%）。`MOTES` からは `duration` / `delay` /
    `drift` を削りました。
  - なお `.aw-motes` の `opacity` アニメーションはオーバーレイ全体の塗り直しになるため
    約 100% まで悪化しました（採用していません）。
- 実測（1366×682、Firefox headless、GPU 無しのソフトウェア WebRender。この環境の値）:
  - 修正前: アイドル **103.9%**（`aw-sway` 1・`aw-drift` 1・`aw-mote` 18・`cube-pulse` 1・`wc-bob` 1）
  - 修正後: **14.5〜19.8%**（同一セッションで 3 回計測）
  - 内訳: `* { animation: none }` で 1.2%、テーマの装飾を `display: none` にすると 9.8%
    （＝cube-ui の `cube-pulse` と whale-chan-pet の `wc-bob` で約 10%）、`.aw-motes` の
    ドリフトが約 3%。テーマ側でこれ以上削れるところはほぼありません。
- 見た目: 鯨・光条の位置・濃さ・マスクは変えていません（静止するだけ）。前後で 1366×682 の
  スクリーンショットを比べると平均輝度 19.05 → 19.21、平均差分 2.8/255
  （アニメーションの位相の差を含む）。海雪は「粒ごとの明滅」から「層ごとのゆっくりした漂い」に
  変わりました。
- `prefers-reduced-motion: reduce` は、残った海雪のドリフトを止める指定に更新しました。
- 確認: `node --check`、モジュール登録のスモークテスト、CSS の波括弧、
  `document.getAnimations()` の棚卸し（`cube-pulse` / `aw-mote-drift` / `wc-bob` の 3 つだけ）、
  4 つのアートワークが同じ CSS を使うこと（バリアントに関係なく効果あり）。
- 再計測: 計測ツールはこのリポジトリの外の `creator/tmp/tools/cpu-probe.mjs` です。トークンは
  `journalctl --user -u dsh-web.service --no-pager | grep -o "token=[A-Za-z0-9_-]\{20,\}"` で
  取得し、`creator/` 直下から
  `PHASES='[{"name":"idle","settleMs":2500,"measureMs":6000}]' node tmp/tools/cpu-probe.mjs "http://127.0.0.1:3080/?token=<TOKEN>"`
  のように実行します。
- 備考: GPU が有効なブラウザでは絶対値は下がりますが、`filter` + `transform` アニメーションと
  巨大な `mask-image` が重いという傾向は同じです。残る約 10% は他プラグイン由来で、
  このテーマの範囲外です。

### 2026-11-10 追記12: 胸ビレの白飛びを抑える（`.aw-whale` の不透明度）

- 依頼: 画面下の大鯨で胸ビレの発光が強く、その上に来る本文や入力欄の文字が見づらい。
  発光を抑えたい（必要なら ComfyUI を使ってよい）。
- 原因: ネオン版の胸ビレは画像上で純白（輝度 1.0）まで飛んでおり、`opacity: 0.72` の
  まま会話欄の下地に重なっていました。ラベル色 `#e6f6ff` は明るいため、下地が明るいと
  コントラストが落ちます。
- 変更（`client.js` のみ・1 か所）: `.aw-whale` の `opacity` を `0.72` → `0.35`。
  コメントに理由と調整方法を残しました。アートワーク（3 つの data URI と手描きの線画
  SVG）は未変更です。
- 検討した別案: 胸ビレの領域だけ画像側で暗くする案（輝度を下げ、青のランプで色を
  引き直す）も試しましたが、胸ビレは白飛びしていて階調が無いため、輝度を落とすと
  細部の無い青い塊になり、粒子の質感が失われて不自然でした。レイヤの透過なら
  絵柄をそのままに光の量だけを減らせます。
- 見え方（`simulate.py` と同じ配置式で背景に重ねた合成プレビュー、1440×900、会話
  テキストを模した行つき）: 胸ビレ周辺の最大輝度 **0.72 → 0.40**、95 パーセンタイル
  0.63 → 0.36、平均 0.30 → 0.20。鯨の形・目・粒子は残り、胸ビレは白ではなく淡い青に
  なります。
- 確認: `node --check`、CSS の波括弧（33/33）、差分は `+9 / -2` の 1 か所のみ、
  埋め込み画像（3 つの data URI）は md5 一致で未変更。実画面は 0.45 の状態を一度確認
  したうえで「もう少し抑える」との指示により 0.35 にしました。この値の最終確認は
  ページ再読み込み後にユーザーが行います。
- 調整: `client.js` の `.aw-whale` の 1 か所だけです。さらに抑えるなら 0.30、
  鯨を出したいなら 0.50〜0.72。
